## Деплой на Vercel

### Вариант 1: Drag & Drop

1. Зайди на [vercel.com](https://vercel.com)
2. Создай новый проект
3. Перетащи все файлы (index.html, manifesto.html, company.html) в область деплоя

### Вариант 2: GitHub

1. Скопируй файлы в новую папку на компьютере
2. Создай репозиторий на GitHub
3. Загрузи код
4. Подключи к Vercel
